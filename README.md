# Achyut Savadatti — Portfolio Website

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript. It is designed for GitHub Pages and does not require a build tool.

## Files
- `index.html` — page content and structure
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile navigation and project case-study popups

## Before publishing
1. Replace `YOUR.EMAIL@example.com` in `index.html` with your professional email address.
2. Update the LinkedIn profile URL.
3. Confirm your current job title, employment dates and whether Fifth Estate should be shown as a past or current role.
4. Add your approved resume PDF to this folder (for example, `assets/Achyut-Savadatti-Resume.pdf`) and add a resume download link.
5. Replace the typographic project artwork with approved campaign images, videos or mockups. The current visual covers are original CSS artwork, not actual campaign assets.
6. Review every project description and remove or change anything that does not accurately reflect your contribution.
7. Add verified results and metrics only where you have evidence.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `achyut-portfolio` (or another name you prefer).
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will usually be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Updating the website
Edit the relevant file, commit the changes to the `main` branch, and GitHub Pages will publish the update automatically.

## Notes
- Google Fonts are loaded from Google Fonts; a system-font fallback is included.
- All project cards work as interactive case-study dialogs.
- No contact form or backend is included. The email link uses `mailto:`.
